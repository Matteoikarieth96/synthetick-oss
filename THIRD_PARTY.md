# Third-party notices

## Dependencies

Installed from npm, not copied into this repository. A scan of both lockfiles found no AGPL, SSPL, BUSL or commercial licenses.
Regenerate the full list at any time:

```bash
npx license-checker --production --summary --excludePrivatePackages
cd sail-agent && npx license-checker --production --summary --excludePrivatePackages
```

Worth knowing:

- `ffmpeg-static` (root dependency, GPL-3.0-or-later wrapper) downloads a GPL ffmpeg build at install time. It is run as a separate process by the X bot video feature only. If you ship a container image, you convey GPL binaries: consider removing it or using a system `ffmpeg`.
- `@img/sharp-libvips-*` (LGPL-3.0-or-later) are optional prebuilt binaries pulled in by Next.js and loaded dynamically.
- `caniuse-lite` data is CC-BY-4.0 (attribution: Alexis Deveria and contributors).
- `@sail.money/sailor` (sail-agent dev dependency) ships an MIT license.

## Loaded at runtime from the web (not bundled)

Google Fonts: Space Grotesk and IBM Plex Mono (SIL OFL 1.1). pdf.js comes from the `pdfjs-dist` npm package (Apache-2.0) and is served by the app's own server.
Asset icons without a vendor logo are loaded by the browser from Google's favicon service and DuckDuckGo's icon service.
Chainlink feed addresses come from Chainlink's public reference data directory. These requests send the visitor's IP address to those services; see docs/PRIVACY.md.

## Smart contract dependencies (not vendored)

`sail-agent/contracts/foundry.lock` pins forge-std (MIT or Apache-2.0) for the contract tests.
OpenZeppelin Contracts v5.1.0 is only needed if you add Sail's GPL-2.0-or-later templates yourself (see `NOTICE.md`).

```bash
cd sail-agent/contracts && forge install foundry-rs/forge-std@v1.16.2
```
