# Brief

- **Topic and key idea:** SyntheTick turns an investment thesis into audited picks, and is now open source (MIT). Viewer should leave with: it never invents data, and they can contribute.
- **Audience:** developers, fintech and crypto builders who might contribute; also curious investors.
- **Length and format:** about 80 seconds, 16:9 (1920x1080), silent with burned-in captions.
- **Language:** English.
- **Voice:** none. macOS system voices are not licensed for public sharing, so the published video is captions only.
- **Must-use facts (all from docs/DOCUMENTATION.md):** up to 10 picks, score 0 to 100, three enforcement layers (SQL filter, code audit, LLM audit), honest empty result, dash instead of missing data, API plus MCP, MIT license.
- **Tone, colors, call to action:** plain and confident, no hype. Default whiteboard palette. Call to action: clone, run, send a pull request.
- **Assumptions made:** "bond funds" instead of "bonds" because only bond ETFs are in the universe. No market numbers are quoted, so nothing in the video goes stale.
